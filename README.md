# Snake Game

Jogo da Cobrinha (Snake Game) desenvolvido como projeto de estudos para praticar lógica de programação, manipulação de eventos e desenvolvimento de aplicações em Python.

## Tecnologias utilizadas

- Python

## Funcionalidades

- Controle da cobra pelo teclado;
- Sistema de pontuação;
- Crescimento da cobra ao coletar alimentos;
- Detecção de colisões;
- Reinício da partida após o fim do jogo.

## Objetivo

Este projeto foi desenvolvido com o objetivo de aprimorar conhecimentos em programação, aplicando conceitos de lógica, estruturas de repetição, condicionais e organização de código na construção de um jogo clássico.

## Como executar

1. Clone este repositório.
2. Certifique-se de ter o Python instalado.
3. Execute o arquivo principal
